# Specifications

Реализация полного функционала NiimBlue iOS с поддержкой импорта, пакетной печати, настроек и полного тестирования

## Functional Requirements

- Импорт JSON шаблонов из файлов
- Просмотр этикеток перед печатью
- Пакетная печать по CSV с подстановкой переменных
- Панель настроек (язык, принтер, единицы измерения)
- Оконка About с информацией о приложении
- Единицы тестирования (unit/UI tests)
- Оптимизация производительности

## Non-Functional Requirements

- Поддержка Swift 5.9+
- Использование только approved технологий
- Сохранение архитектуры проекта
- Full documentation EN+RU
- Idempotent build process

## Acceptance Criteria

- Успешный импорт экспортированных JSON шаблонов
- Корректная отрисовка предпросмотра этикеток
- Пакетная печать 100+ записей CSV без ошибок
- Все настройки сохраняются после перезапуска
- Минимум критических багов
- Покрываемость тестами >60%

## Out of Scope

- Замена существующих технологий
- Изменение архитектуры
- Новые внешние зависимости
- Webview для Fabric.js
