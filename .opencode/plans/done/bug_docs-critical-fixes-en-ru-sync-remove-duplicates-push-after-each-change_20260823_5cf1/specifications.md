# Specifications

Исправление критических ошибок в AGENTS.md и AGENTS.ru.md: 1) синхронизация статусов [x] для Phase 5 и Phase 7 в русском документе, 2) удаление дублирующего блока Phase 10-11 в английском документе, 3) синхронизация разделов Project State между EN и RU версиями, 4) обязательный коммит + пуш на GitHub после каждого отдельного исправления

## Functional Requirements

- Исправить статус Import label function в Phase 5 AGENTS.ru.md: [ ] -> [x]
- Исправить статус Batch print support в Phase 7 AGENTS.ru.md: [ ] -> [x]
- Удалить дублирующий блок Phase 10-11 в строках 1135-1148 AGENTS.md
- Синхронизировать раздел Project State в AGENTS.md и AGENTS.ru.md
- Выполнить коммит и пуш после каждого отдельного исправления
- Проверить наличие и состояние тестов в репозитории

## Non-Functional Requirements

- Не использовать sed/echo/cat для редактирования - только read + edit
- В каждом коммите менять только один файл или одну категорию исправлений
- Проверять результат каждого edit перед следующим шагом
- При проблемах с xcodebuild запрашивать явную команду установки xcode-select --install
- Сохранять full-volume формат AGENTS.md и AGENTS.ru.md

## Acceptance Criteria

- После исправления статусы Phase 5 и Phase 7 в AGENTS.ru.md должны быть [x] и совпадать с AGENTS.md
- Дублирующий блок Phase 10-11 в AGENTS.md должен быть удален
- Разделы Project State в AGENTS.md и AGENTS.ru.md должны быть синхронизированы
- Все изменения должны быть отправлены на GitHub через коммит + пуш
- Тесты должны быть проверены и выполнены локально (если возможно)

## Out of Scope

- Изменение структуры проекта
- Изменение логики приложения
- Добавление новых функций
- Изменение AGENTS.md или AGENTS.ru.md как full-volume документов
