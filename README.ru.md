# NiimBlue iOS

Нативное iOS-приложение для управления и печати этикеток на принтерах NIIMBOT.

## Обзор

NiimBlue iOS предоставляет полный функционал веб-версии NiimBlue в нативной iOS-среде.

Репозиторий хранит только исходный код и конфигурацию.

Проект **не предназначен** для замены существующего веб-приложения NiimBlue.

## Основная цель

Начиная с пустого iOS-проекта, создание полностью рабочего приложения для печати этикеток должно требовать только:

1. Клонирования репозитория
2. Запуска процесса сборки

После сборки приложение будет содержать:
- Полный UI на SwiftUI
- CoreBluetooth-клиент для принтеров NIIMBOT
- NSLocalSocket-клиент для USB-соединения
- Нативный редактор этикеток с множественными объектами
- Сохранение/загрузку этикеток
- Предпросмотр печати с постобработкой

Процесс сборки должен всегда быть воспроизводимым.

## Установка

### Требования

- Xcode 14.0 или новее
- macOS 12.0 или новее
- Устройство с iOS 15.0 или новее

### Сборка

1. Клонирование репозитория:

```bash
git clone <repository-url>
cd NiimBlueiOS
```

2. Открытие Xcode-проекта:

```bash
open NiimBlueiOS.xcodeproj
```

3. Выберите вашу команду разработчика и сертификат подписания

4. Выберите целевое устройство или симулятор

5. Сборка и запуск:

```bash
xcodebuild -scheme NiimBlueiOS -destination 'platform=iOS Simulator,name=iPhone 15'
```
